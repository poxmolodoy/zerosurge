# Руководство по участию в разработке ZeroSurge

Спасибо за интерес к проекту ZeroSurge! Мы приветствуем вклад сообщества в развитие открытого, приватного и научно обоснованного трекера.

---

## 🏛️ Главные принципы проекта

1. **Strictly Local-Only (Никакой телеметрии):**
   В коде приложения категорически запрещены любые аналитические скрипты, трекеры активности, внешние API и сохранение данных в облаке. Все вычисления производятся исключительно на устройстве пользователя.
2. **Научная обоснованность (Zero Hallucinated Evidence):**
   Любые медицинские или биологические тезисы должны сопровождаться ссылками на рецензируемые клинические исследования (DOI, PubMed, ВОЗ, EFSA).
3. **Хирургическая точность изменений:**
   Изменяйте только те файлы и строки, которые непосредственно относятся к вашей задаче. Не смешивайте рефакторинг с функциональными изменениями.

## 🛠️ Локальное окружение

### Требования

- Node.js 20+
- npm 10+

### Установка зависимостей

```bash
npm ci
```

### Запуск в режиме разработки (веб)

```bash
npm run dev
```

### Запуск Electron-приложения локально

```bash
npm run build
npm run electron:start
```

## 🧪 Тестирование и проверки качества

Перед созданием Pull Request убедитесь, что все автоматические проверки проходят локально:

```bash
# 1. Проверка типов TypeScript
npx tsc --noEmit

# 2. Проверка стилей кода (Prettier)
npm run format:check

# 3. Статический анализ (ESLint)
npm run lint

# 4. Модульные и интеграционные тесты
npm test

# 5. Проверка офлайн-целостности (отсутствие внешних вызовов)
npm run build
npm run check:offline
```

## 📝 Оформление коммитов

Мы используем соглашение [Conventional Commits](https://www.conventionalcommits.org/ru/v1.0.0/):

- `feat:` новая функциональность (например, `feat(taper): add caffeine reduction calculator`)
- `fix:` исправление ошибки (например, `fix(export): sanitize imported JSON fields`)
- `docs:` изменения в документации
- `test:` добавление или исправление тестов
- `chore:` рутинные задачи, обновление зависимостей или конфигурации
