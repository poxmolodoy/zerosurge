## 1. Архитектурная модель угроз (Threat Model)

ZeroSurge спроектирован по принципу **Zero-Knowledge Client-Side Only**:
- Все пользовательские данные (время отказа, история срывов, дневник самочувствия, финансовые затраты) хранятся исключительно на стороне клиента в `localStorage`.
- Приложение **не отправляет** телеметрию, персональные данные или аналитику на внешние серверы.
- Полная автономность: приложение не имеет уязвимых серверных API-эндпоинтов, баз данных или сторонних трекеров.

## 2. Анализ и нейтрализация векторов атак

### 2.1 Защита от межсайтового скриптинга (XSS Prevention)
- **Отсутствие опасных методов:** В кодовой базе полностью отсутствуют вызовы `dangerouslySetInnerHTML`, `eval()`, `new Function()` и инлайн-обработчики JavaScript.
- **Декларативный рендеринг React:** Все строковые значения, выводимые на экран, автоматически экранируются виртуальным DOM React.
- **Вектор Canvas 2D:** Модуль `NeuralBackground.tsx` использует контекст `CanvasRenderingContext2D` с прямым рисованием геометрических примитивов (`arc`, `lineTo`, `stroke`) без парсинга HTML или DOM-манипуляций.

### 2.2 Валидация и защита хранилища (`localStorage` Hardening)
Для защиты от повреждения данных, ручных модификаций через DevTools или вредоносных расширений браузера реализован строгий модуль [securityValidator.ts](file:///d:/antigravityProjects/zero-surge/src/utils/securityValidator.ts):
- **Защита от Prototype Pollution:** Исключено копирование служебных ключей `__proto__`, `constructor`, `prototype`. Все объекты возвращаются как чистые плоские структуры.
- **Ограничение числовых диапазонов (Bounds Clamping):**
  - Количество банок: `[0; 50]` (защита от переполнения и `NaN`).
  - Количество чашек кофе: `[0; 50]`.
  - Стоимость порции: `[1; 10 000]` ₽.
  - Оценки в чек-инах: строго целочисленные значения `[1; 5]`.
- **Проверка целостности дат:** Все даты проверяются через парсер `Date.parse()` и регулярные выражения `^\d{4}-\d{2}-\d{2}$`. При обнаружении невалидного формата происходит безопасный откат к текущему моменту без сбоя приложения.

### 2.3 Безопасность ресурсов и защита от утечек памяти (DoS / Performance)
- **Управление анимационным циклом (Lifecycle Guard):**
  - В `NeuralBackground.tsx` внедрен слушатель `document.visibilitychange`. Когда вкладка скрыта или экран заблокирован, цикл `requestAnimationFrame` немедленно приостанавливается, предотвращая нагрев устройства и разряд батареи.
  - Поддержка `prefers-reduced-motion`: на устройствах с включенным режимом снижения движения холст отрисовывает один статичный кадр без запуска постоянного цикла.
- **Слушатели событий:** Все обработчики (`mousemove`, `touchmove`, `resize`) зарегистрированы с флагом `{ passive: true }` и гарантированно отписываются при размонтировании компонентов в блоках `return () => { ... }`.

## 4. Безопасность Electron и десктопной Portable-версии

В рамках подготовки автономного Windows-бинарника (`release/ZeroSurge-1.0-Portable.exe`) проведен аудит окружения исполнения Chromium / Node.js:

1. **Изоляция контекста (Context Isolation):**
   - В `electron/main.cjs` строго заданы параметры:
     ```javascript
     webPreferences: {
       preload: path.join(__dirname, 'preload.cjs'),
       contextIsolation: true,
       nodeIntegration: false,
       backgroundThrottling: false,
       devTools: process.env.NODE_ENV === 'development',
     }
     ```
   - Рендерер не имеет прямого доступа к API Node.js (`fs`, `child_process`, `net`).
   - `preload.cjs` передает в глобальный скоуп (`window.electronAPI`) исключительно флаг платформы (`isDesktop`, `platform`), без проксирования небезопасных методов.
2. **Безопасная обработка внешних ссылок:**
   - Все исходящие переходы (кнопки открытия медицинских исследований и источников) перехватываются `setWindowOpenHandler`.
   - Запрещено создание дочерних веб-вью (`{ action: 'deny' }`). Допускаются только протоколы `http:` и `https:`, которые направляются в браузер ОС пользователя через `shell.openExternal()`. Схемы `file:`, `javascript:`, `data:` блокируются.
3. **Блокировка повторных экземпляров (Single Instance Lock):**
   - Вызов `app.requestSingleInstanceLock()` гарантирует, что запуск второго экземпляра portable-приложения не порождает гонку процессов и не повреждает базу данных `localStorage`. Фокус передается первичному активному окну.
4. **Стабильность счетчика в фоне (Anti-Drift):**
   - `backgroundThrottling: false` отключает агрессивное замедление таймеров Chromium при сворачивании окна, сохраняя точность отсчета времени без искажений при выходе из сна.

## 6. Рекомендации по развертыванию веб-версии (Production Headers)

При размещении статического бандла (на Nginx, Vercel, Cloudflare Pages) рекомендуется активировать следующие заголовки:

```http
Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src 'self' https://fonts.gstatic.com; img-src 'self' data:; connect-src 'self';
X-Content-Type-Options: nosniff
X-Frame-Options: DENY
Referrer-Policy: strict-origin-when-cross-origin
Permissions-Policy: camera=(), microphone=(), geolocation=()
```
